## ⚡ What's Inside

This portfolio isn't just a static resume; it's a living sandbox where I experiment with:

- **Physics-Based UI:** Interactive elements (like the swinging lamp) that react naturally to user input.
- **Micro-interactions:** Smooth, scroll-triggered reveals that guide the eye without overwhelming the senses.
- **The Hacker Aesthetic:** A nod to raw computing, utilizing monospaced system fonts, high-contrast layouts, and terminal-inspired design language.
